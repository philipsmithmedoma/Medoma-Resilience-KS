Line geometry is simplified with Douglas–Peucker at 8 m tolerance (vertices shared by two ways are kept so that junctions survive), coordinates are rounded to 5 decimals, and every tag other than those listed in SPEC.md § 12.2 is dropped. Generated by `node scripts/fetch-osm.mjs`; do not edit by hand.

## Status

The four data files (roads.json, streets.json, power.json, water.json) are not committed yet: the session that built this could not reach Overpass. Until they are, the app and the tests use the hand-designed fallback written by `node scripts/make-geo-fixtures.mjs`: fixture.json (30 ways: 20 named corridor ways and 10 zone ring roads), fixture-streets.json, fixture-power.json and fixture-water.json, which have the same schema. To fetch the real data, run locally:

```
node scripts/fetch-osm.mjs
```

It needs Node 22 and internet access to https://overpass-api.de/api/interpreter, takes a few minutes, fails if a file exceeds its budget, and overwrites this README with the query date and the sizes.
