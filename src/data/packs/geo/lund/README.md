## Status

The four data files (roads.json, streets.json, power.json, water.json) are not committed yet: the session that built this could not reach Overpass. Until they are, the app and the tests use the hand-designed fallback written by `node scripts/make-geo-fixtures.mjs lund`: fixture.json (12 named ways, among them "Trafikplats Lund Norra" and "Trafikplats Lund Södra", and 63 zone ring segments), fixture-streets.json, fixture-power.json and fixture-water.json, which have the same schema. To fetch the real data, run locally:

```
node scripts/fetch-osm.mjs lund
```

It needs Node 22 and internet access to https://overpass-api.de/api/interpreter, takes a few minutes, fails if a file exceeds its budget, and overwrites this README with the query date and the sizes. The queries are in `scripts/overpass/lund/`; `--bbox 55.58,12.84,55.93,13.74` sets the box explicitly.
